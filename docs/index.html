開始使用

  1. 打開 ShieldBlock，依照設定精靈操作。
  2. 到 iPhone「設定 → App → Safari → 延伸功能」，打開所有 ShieldBlock 項目。
  3. 「ShieldBlock Advanced」請允許「所有網站」，才能使用彈窗攔截、防詐騙與網頁小幫手。
  4. 回到 App，看到「保護中」就完成了。

常見問題

某個網站壞掉、無法正常使用？

在 Safari 點網址列旁的選單按鈕（「大小」或「⋯」）→ ShieldBlock，關閉「在此網站擋廣告」，這個網站就會加入白名單。也歡迎來信告訴我們網址，我們會盡快修正規則。

為什麼還是看到廣告？

請確認所有延伸功能都已開啟，並在 App 中更新規則。仍有沒擋到的廣告，可以用「隱藏網頁元素」自己點選隱藏，或來信回報。

可以擋 YouTube、Instagram 等 App 裡的廣告嗎？

不行。這些 App 的廣告和內容來自同一個伺服器，任何擋廣告工具都無法在不影響內容的情況下攔截。ShieldBlock 主要保護 Safari 網頁。

防詐騙警告的資料從哪裡來？

來自內政部警政署 165 反詐騙諮詢專線公布的開放資料，ShieldBlock 只轉述政府公告。如認為誤判，可選擇「仍要前往」，並歡迎來信告訴我們。

如何恢復購買或取消訂閱？

恢復購買：App「升級 Pro」頁右上角的「恢復購買」。取消訂閱：iPhone「設定 → 你的名字 → 訂閱項目 → ShieldBlock」。訂閱由 Apple 處理，我們無法代為取消或退款，退款請至 reportaproblem.apple.com 申請。

ShieldBlock 會看到我的瀏覽紀錄嗎？

不會。所有判斷都在你的 iPhone 上完成，我們沒有伺服器收集任何資料。詳見隱私權政策。
